# Changelog

All notable changes to this project are documented in this file.

## [0.3.0] - 2026-11-07

### Added

- Optional FLAG, MAPQ, read-length, and htslib expression filters.
- A `@CO` header marker (`HUSK:1`) identifying Husk output and its version.

## [0.2.0] - 2026-11-06

### Added

- Optional reproducible random downsampling by fraction or read count, in
  total or per-sample mode.

## [0.1.0] - 2026-11-04

First public release.
